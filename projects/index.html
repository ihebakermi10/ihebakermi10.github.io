    Featured Project

    Hutchinson AI — Enterprise Multi-Agent Assistant - AppStore

    Built and shipped an internal AI assistant for Hutchinson, orchestrating a DeepAgents supervisor over isolated specialist subagents (employee directory + application catalog) with structured, grounded handoffs, using graph engineering for the supervisor-to-subagent routing and loop engineering to keep the tool-calling loop of every agent bounded and recoverable. Retrieval runs through a dedicated OpenSearch MCP server exposing lexical/fuzzy search tools, with every subagent delegation and MCP tool call traced end-to-end via MLflow. Served on Azure infrastructure through an Azure OpenAI-compatible LLM Hub gateway running the GPT-5.6 model family, with FastAPI WebSocket streaming for real-time responses. Long-running jobs are backed by a Redis stream queue with dead-letter handling and LangGraph/PostgreSQL checkpointing, so conversations survive worker restarts.
